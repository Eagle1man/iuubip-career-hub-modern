# Центр карьеры · Южный университет (ИУБиП) — современная версия

Форк сайта карьерного центра: новый дизайн в стиле Synergy, mobile-first вёрстка,
фирменные цвета ИУБиП, базовая защита от XSS и автотесты на весь функционал.

Оригинал (`iuubip-career-hub`) не изменялся — это отдельный проект.

## Что изменилось относительно оригинала

**Дизайн**
- Полностью переписана дизайн-система на CSS-переменных: фирменный синий
  `#0e2f5f`, золото `#c9a227`, зелёный `#1a9e4b`, красный `#c8102e`.
- Новая шапка, hero с поиском и 4 плитками статистики, карточки с мягким
  подъёмом при наведении, сегментные «пилюли» навигации, круглые KPI.
- Убран старый «серый» стиль (Georgia, `#f2f3f5`, квадратные кнопки).

**Mobile-first**
- Нижняя навигация «как в приложении»: 5 кнопок + шторка «Ещё» со всеми разделами.
- Фильтры направлений на телефоне — в bottom-sheet (кнопка «Фильтры и направления»).
- Модальное окно «Заказать звонок» на телефоне — тоже bottom-sheet.
- Тап-таргеты ≥ 44 px, поля ввода `font-size: 16px` (iOS не зумит), учёт
  `env(safe-area-inset-bottom)` для iPhone, `theme-color`, `viewport-fit=cover`.
- Брейкпоинты: ≤480 (телефон), ≤860 (планшет/телефон), ≥1024 (десктоп).

**Безопасность**
- Экранирование всех динамических данных (`esc()`) — вакансии, стажировки,
  академии, кураторы, hh.ru.
- Проверка схемы ссылок (`safeUrl()`): `javascript:` и разрыв атрибута кавычками
  превращаются в `#`.
- Все внешние ссылки — `target="_blank" rel="noopener noreferrer"`,
  `window.open(..., 'noopener')`.
- `<meta>` CSP, `referrer`, а полный набор заголовков — в `_headers` и `nginx.conf`.
- Валидация форм (имя, телефон ≥ 10 цифр); персональные данные не уходят на сервер.

**Автотесты**
- 51 тест на Node + jsdom: структура, целостность разметки, навигация, все
  9 разделов, вакансии, стажировки, конструктор резюме, модалка, запись,
  hh.ru, шторки, XSS.

**Деплой**
- `_headers` (Cloudflare Pages / Netlify), `deploy/nginx.conf` (VPS),
  `DEPLOY.md` с инструкциями и CI-воркфлоу.

## Запуск

```bash
# сайт: просто откройте index.html двойным кликом — работает офлайн
start index.html

# тесты
npm install
npm test
```

Ожидаемый результат: `pass 51`, `fail 0`.

## Структура

```
index.html                          весь сайт: разметка + CSS + JS, без зависимостей
_headers                            заголовки безопасности для Cloudflare/Netlify
deploy/nginx.conf                   конфиг nginx для VPS (HTTPS, CSP, кэш)
DEPLOY.md                           три сценария деплоя + чек-лист
tests/static.test.mjs               структура, метатеги, CSS-каркас, целостность
tests/dom.test.mjs                  рендеринг и навигация
tests/flows.test.mjs                конструктор резюме, формы, hh.ru, шторки
tests/security.test.mjs             экранирование, XSS, CSP, безопасные ссылки
tools/update_vacancies.py           парсер вакансий с trudvsem.ru
.github/workflows/weekly-vacancies.yml  автоподбор вакансий (понедельник, 06:00)
.github/workflows/tests.yml         автотесты на push и pull request
```

## Обновление вакансий

Подборка живёт между маркерами `// VAC-DATA-START` и `// VAC-DATA-END`.
Каждый понедельник GitHub Actions запускает `tools/update_vacancies.py`,
переписывает блок и коммитит `index.html`. Вручную — вкладка Actions →
*Weekly vacancies refresh* → *Run workflow*. Локально:

```bash
python tools/update_vacancies.py
npm test
```

## Технологии

HTML + CSS + JS в одном файле, без фреймворков, CDN и внешних шрифтов.
Тесты: Node.js `node:test` + jsdom.

## Известные ограничения

- CSP оставлен с `'unsafe-inline'` для скриптов: в разметке используются
  атрибуты `onclick` (логика оригинального сайта сохранена намеренно).
  Полный отказ от них — отдельная задача на будущее.
- В оригинальном коде есть неиспользуемая функция `uSearch()`, ссылающаяся на
  отсутствующий элемент `#usearch`. Логика сохранена как есть, тест это
  фиксирует в списке известных «мёртвых» ссылок.
- GitHub Pages не поддерживает пользовательские заголовки — там работает только
  `<meta>` CSP.
